# GeoNav：论文证据与页面规划示例

本案例说明如何组织多模块导航论文的机制、实验与讨论。页数、模块和指标仅对应本案例；通用构图方式见 [参考版式](../../references/reference-patterns.md)。

论文：Xu 等，*GeoNav: Empowering MLLMs with dual-scale geospatial reasoning for language-goal aerial navigation*，Pattern Recognition 177 (2026), 113365，DOI [10.1016/j.patcog.2026.113365](https://doi.org/10.1016/j.patcog.2026.113365)。本项目不打包论文全文和第三方原图。

## 证据组织

读取正文和附录，区分任务假设、方法机制、主要实验、失败案例与作者结论。表格保留指标方向、数据划分、监督设置、均值和标准差。不同表的完整模型结果有差异时按原表说明，不能为了叙事一致而改数据。

## 八页规划示例

| 页 | 内容 | 主要视觉 |
|---:|---|---|
| 1 | 现有问题、任务边界 | 尺度跨度、相似目标、重复探索的具体案例 |
| 2 | 研究定位 | 代表路线、能力、关键缺口及可比较的条件 |
| 3 | MNS 与总体框架 | 多阶段调度和双尺度记忆的交互 |
| 4 | SCM | 地理先验、感知、空间注册、全局地图更新 |
| 5 | HSG | 层次关系、查询回退和必要融合公式 |
| 6 | 整体结果和任务难度 | 原生数据表，突出主要对照与例外 |
| 7 | 消融、骨干、高度与阶段进展 | 原生表格、论文统计图与解释边界 |
| 8 | 贡献、失败、局限与后续假设 | 贡献对应证据，失败案例对应局限 |

研究定位可在材料较少时并入任务页；方法页可按共享输入或状态合并。是否独立成页取决于证据和可读性，不由模块名或公式数量决定。

## 素材与原生对象

从 PDF 内嵌对象直接提取路线图、关键帧、地图、图结构和统计图，建立来源与使用位置的对应关系。核对每张复合图的文字、图例和子图完整性。机制采用可编辑图形和短标签，必要公式转换为 `a14:m / m:oMath`，详细推导放备注。

中文使用仿宋 GB2312，英文和数字使用 Times New Roman，分别设置文本 run。字体 XML 中 GB2312 `charset` 为 `-122`，EOT 二进制字段为 `134`。这些是不同类型的表示，不应对字体二进制全局替换。详见 [兼容性指南](../../references/powerpoint-compatibility.md)。

## 比较边界与交付

同屏展示主张与支持它的证据。综述区分直接实验比较、方法接入和相关工作介绍；不能把没有直接对比的数据写成胜负结论。来源与完整讲解放备注，影响读数的指标、条件与局限留在图表附近。

交付前进行结构检查、逐页渲染与内容复核。有桌面 PowerPoint 时验证打开和编辑；实际未执行的验证如实说明。局部修改只调整指定内容，并核对其他页面及共享资源的影响。
