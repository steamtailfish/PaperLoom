# 让原图与实验承担解释

有效密度是同页讲清更多相关关系，不是堆字、堆公式或凑分区。按“原图/数据 → 需要补的标注 → 仍缺的短句”写页面，不先写大段摘要再找配图。

## 逐图安排

通读所有 Figure 与图注，填入计划的 `figure_usage`。每项含 `id`、`source`、`slides`、`purpose`、`route`；未用时写 `exclusion_reason`。使用前后另记录 `completeness_verified` 和实际检查结果。没有固定图片配额；任务图、总架构、内部表示及结果图只要能解释核心内容，就优先安排，不能因提取麻烦默默跳过。

复合图保留子图、标注、箭头和图例。使用 [原生 Form 导出](figure-extraction.md) 获取完整对象。图太小先腾出重复文字的空间；仍不清楚则增加机制展开页。局部放大必须标明与完整图的对应关系。完整结构已有原图时，可编辑补充图只解释更新条件、接口或训练差异，不再用一套泛化方框重复完整架构。

## 逐式取舍

在 `equations` 为论文公式记录 `id`、`source`、`slides`。独立上屏必须写 `purpose`，具体到该式能说明哪种独特关系。不上屏写 `exclusion_reason`，说明内容如何被图解覆盖或为何属于补充推导。论文原图内自带数学标签可原样保留，不计作另排公式，也不破坏完整图去删除它们。

一般优化器、MSE、PPO、残差恒等式和距离阈值通常用“监督对象 → 更新对象”“抵达当前航点 → 重规划”等图中标签即可。数学方法本身是贡献时保留必要定义、目标和推导关系。零个独立公式可以是正确选择，机械删掉核心数学关系同样不可取。

## 同页组合与增加页数

例如导航论文：完整执行轨迹 + 高低层职责 + 重规划条件；地图原图 + 通道含义 + 地图消融；训练泳道 + 奖励行为 + 参数敏感性；难度对照 + 完整定性案例。组合必须增加互补信息，不能图中一个节点、旁边一个公式、下面一段话讲三遍。

所有重要实验必须可见，但不要求每表独占一页。保留同口径基线、必要指标、完整消融及不利结果；表格过大时拆页，不能缩成几个最大收益数字。原图、原生表格和短标签中的文字与解释散文分别审阅。

## 交付前对照

逐页问：移除旁边的段落后，图能否讲清机制？不能时是缺接口标注、原图被拆碎，还是确实需要解释？先修复原因。逐图回查有无未安排的核心素材，逐式回查有无只因论文写了就搬上屏的公式，再与 AeroDuo 参考比较图文协作及内容组织。不能以页数、公式数、图片数或自动分数证明达到参考质量。
