# 逐页质量关卡

制作时在工作目录记录计划和检查结果，最终交付只给用户需要的文件。以下是自查流程，不要求用户逐项审批。

## 写页面代码前

新建或整体重做时，先实际查看包内 [AeroDuo 六页参考稿](../examples/aeroduo-reference/AeroDuo_组会汇报_合并精简6页版.pdf) 的全部页面。每页计划的 `layout.reason` 写清借鉴的参考页及迁移方式，或说明为何选择其他结构；页数和布局不机械照搬。记录真实查看情况，不能只读文字说明便声称看过参考 PDF。用户模板优先。

完成 `slide-plan.json`，可从 [模板](../examples/slide-plan.template.json) 复制。对每页回答：

模板中的 `reference_profile` 与 `reference_pdf` 相对 skill 根目录解析；`reference_review` 记录实际看过的参考页与未完成的检查，不能预填为已完成；证据索引、素材和生成文件相对工作目录解析。纯文字材料可将 `source_pdf` 和 `pdf_page` 设为 `null`，记录 `source_type` 与段落/表格定位，不虚构 PDF 页码。

`source_completeness_checked` 仅表示核对素材是否忠实完整，不表示论文足够复现；缺少的实现细节单独记录。设计阶段保持 `review.stage="planned"` 和 `render_inspected=false`，真正看过渲染结果后再更新，不能混同计划核对与视觉检查。

1. 听众看完能够说明哪一件具体事情？
2. 哪张图、哪组数据或哪个可编辑关系承担主要解释？素材从哪里来，是否完整？
3. 哪些互补证据应同页出现？哪些内容只是重复上一页？
4. 图中的接口、对照、条件或空间关系能否直接读懂？
5. 什么必须可见，什么属于备注讲稿？

只有主题和三条概述、没有具体视觉或证据的计划需要改写。允许严谨的综述/总结页以文字为主，不为每页强塞图片。页数先服从用户要求；没有指定时用覆盖与可读性决定，不因默认结构强行拆页。

## 草稿导出后

```bash
python scripts/validate_pptx.py final.pptx --report work/structure.json
python scripts/audit_slide_quality.py final.pptx --report work/slide-quality.json
```

第一条检查包结构、关系、字体和原生公式等；第二条检查可观察的文本/对象风险。通过第一条不代表文字写得好，通过第二条不代表视觉达标。

质量审计的字数和几何指标只是提示：表格数字与正文分开统计，图片外框不等于有效内容，原生机制图可能没有图片。群组、旋转、母版继承等情况以报告中的测量范围为准。不能靠把段落拆成小文本框、给背景命名为“证据图”或放大无信息图片来消除警告。

## 渲染后必须实际查看

没有专用导出工具时，执行 [公开渲染回退](rendering.md)。PPTX 可经 LibreOffice 转 PDF 后逐页渲染，也可直接渲染已有工具导出的 PDF。

先将全套页面看作缩略图，再逐页按放映尺寸检查；必要时放大看坐标和公式。记录每页的真实问题、采取的动作及复看结果，不能用一组默认 `true` 代替检查。

| 问题 | 应采取的动作 |
|---|---|
| 整页主要是同质文字卡片 | 改为输入输出、任务对照、机制流程或结果矩阵；无必要的框直接删掉 |
| 主要图太小、周围留白，但旁边还写大段说明 | 先移走重复散文，扩大证据，必要时拆出局部放大并加对应标签 |
| 总流程很简单却占一整页 | 压成总览条，同页展开难点、实例或训练/执行差异 |
| 相邻两页必须来回翻才能拼出同一机制 | 尝试合页或重复最小定位条，不重复完整说明 |
| 数据变成漂亮但缺比较条件的大数字 | 恢复对照、单位、划分和必要行列；用局部高亮引导阅读 |
| 表格/图例读不清 | 重分区、移除重复表头或拆页；不继续缩字号 |
| 标题、图注和正文讲了同一句话 | 留最有用的一处，腾出的空间给证据 |
| 公式与图关系不明 | 把公式放到对应变换附近，注明变量所对应的对象；多余推导进备注 |

内容复核同时检查：数字与来源一致，比较口径匹配，图像完整，误差含义可见，作者结论与汇报者解释分明，假设没有写成已证实事实。

每页至少留下一个具体观察，例如“推理端未使用的监督图被误连为输入，已断开并移到训练泳道”，而不是只写“美观：通过”。修订后复看受影响页；若改变整体网格或字体，再看所有相关页。

## 交付边界

交付前清除占位符、未转换公式与示例数字，确认文件路径真实可下载，notes 对应正确页。检查无法执行时明确说明；严禁伪称打开了 PowerPoint 或逐页看过未渲染的文件。不要为了凑一个“质量分”添加无依据数据或跳过检查。
