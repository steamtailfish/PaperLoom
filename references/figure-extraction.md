# 论文图的原生提取

目标是获得论文实际使用的图像资源，并记录它们的来源。**不把整页渲染、局部页面截图或 `page.get_pixmap(clip=…)` 当成原图提取。** 成品 PPT 的整页预览可用于排版检查；预览图片不得回填成论文插图。

## 自动提取

在项目根目录运行（Python 3.10+）：

```bash
python -m pip install "PyMuPDF>=1.24" "Pillow>=10"
python scripts/extract_pdf_assets.py paper.pdf --output work/paper-assets
python scripts/extract_pdf_assets.py paper.pdf --output work/selected-assets --pages 1,3-5
```

`--min-width`、`--min-height` 默认均为 `0`，不会因尺寸小而漏掉面板。只有已检查完整图号清单后，才考虑主动过滤。输出路径由使用者指定；重复运行用新目录，或显式加 `--overwrite`。替换模式不清理旧的无引用文件，以新 `manifest.json` 为准。

脚本使用 `Document.extract_image(xref)` 读取内嵌 Image XObject。同一 xref 只保存一次，`occurrences` 记录各页的全部可定位显示位置。软遮罩使用原图与其 SMask 图像资源重建 alpha PNG，同时保留提取出的原图和遮罩；这个过程没有渲染 PDF 页面。原始提取文件是解码封装后的图片，不承诺等同于 PDF 内压缩流的逐字节内容。[PyMuPDF 图像提取说明](https://pymupdf.readthedocs.io/en/latest/recipes-images.html)

`manifest.json` 包含源 PDF 哈希、资源 xref、页码、bbox、变换矩阵、像素尺寸、文件 SHA-256、提取路线及告警。bbox 使用 PyMuPDF 未旋转页面坐标，单位为 PDF point；Form 的 bbox 单独标为局部坐标。不能直接把这些坐标当作 PPT 像素位置。[PyMuPDF 页面对象说明](https://pymupdf.readthedocs.io/en/latest/page.html)

返回码 `0` 表示完成，`1` 表示输入/参数失败，`2` 表示部分资源失败且清单已保存。必须检查 `errors`、`warnings`，不能只数文件。

## 完整 Figure 仍须人工核对

提取到小部件不代表得到完整 Figure：照片可能是图片对象，箭头是矢量路径，文字是 PDF 文本。为每个拟使用图建立一条核对记录：

| 核对项 | 通过条件 |
| --- | --- |
| 图号与图注 | 论文图号、页码、全部子图含义对应正确 |
| 完整性 | 面板、坐标轴、图例、箭头、标签均存在，无误裁 |
| 清晰度 | 放到预计版面大小后仍可读；避免无依据放大低分辨率照片 |
| 透明度与合成 | SMask 已合并，白/深底均无明显黑块或缺失区域 |
| 科学含义 | 重组布局不改变方向、数值、顺序、比较对象或原文限定 |

使用原生图片查看器检查提取资源；对照论文正文和图注确认语义。允许从**已经提取的原始图片**分离其子面板，但记录父资源哈希与裁剪范围；这不同于从 PDF 页面截图。不得通过裁掉标签来制造更有利的结论。

**复合图示例（GeoNav）：** 第 11 页 Fig. B.6 中，直接提取的图片对象只有背景框、地图和部分彩色文字，许多黑色标题与正文属于额外的原生对象。因此，“图片成功解码且分辨率很高”仍不能判定该图完整；必须保留整个复合图的原生内容，或按下述路线重建。

## 纯矢量或复合图

`vector_form_candidates` 只列出可能包含矢量或复合内容的位置，不自动认定为 Figure，也不导出整页图片。Form 可能包含图片、文字或装饰；矢量路径也可能只是表格线。按以下顺序处理：

1. 查找论文补充材料或作者公开仓库中的原始 SVG、PDF、EPS、PNG 等图件，核对版本和图注。
2. 没有作者图件时，在支持 PDF 原生对象的编辑器中打开页面，选择完整图的对象组，保留字体、裁剪路径和变换，导出选中对象为 SVG/独立矢量 PDF。不能截屏或先转整页位图再裁剪；导出后对照完整性清单。
3. 原生对象无法可靠分离时，用 PPT 原生形状、连接线、表格或图表重绘，并标记“根据论文重绘”。数据按论文表格/坐标核对；不得编造缺失数值。
4. 仍无法可靠重建时，把该图列为待补素材，并先用可核验内容完成其余页面；不要偷偷截图降级。

来源和核对记录放在制作资料或演讲者备注中。除用户主动要求，幻灯片底部不放逐页证据说明小字。
